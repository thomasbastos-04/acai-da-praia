# Açaí da Praia

Cardápio interativo para montar um açaí pelo celular. Escolha o tamanho, até duas frutas, acompanhamentos e coberturas. O total é atualizado ao selecionar o tamanho ou adicionar Nutella.

Na etapa final, **Copiar pedido** coloca o resumo na área de transferência para colar onde preferir. As escolhas ficam no navegador durante a montagem.

## Rodar localmente

O site usa HTML, CSS e JavaScript. Com Python 3 instalado, rode o comando na pasta do repositório.

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Abra [http://localhost:8000](http://localhost:8000) no navegador.
